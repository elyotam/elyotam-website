# ElyotamWebsite

אתר התדמית של Elyotam, בגרסת הצילום הריאליסטי. עמוד אחד, עברית RTL, בלי build step.
הקוד זהה ל-`army-website`, רק הרצף והתזמון הוחלפו.

## הרצה מקומית

```bash
python -m http.server 8092
# http://127.0.0.1:8092
```

חייב לרוץ מעל HTTP ולא מ-`file://`, כי `main.js` הוא ES module.

## איך נבנו הפריימים

7 קטעים של 158 פריימים ב-24fps. כל קטע מתחיל בדיוק בפריים שהקודם נגמר בו, אז מקטעים
2 עד 7 נזרק הפריים הראשון: `158 + 6 x 157 = 1100`.

```bash
ffmpeg -i 1.mp4 ... -i 7.mp4 -filter_complex \
  "[0:v]setpts=N/24/TB[v0];[1:v]trim=start_frame=1,setpts=N/24/TB[v1];...
   concat=n=7:v=1:a=0,split=2[d][m];[m]crop=ih*9/16:ih[mc]" \
  -map "[d]"  -fps_mode passthrough -c:v libwebp -quality 82 frames/frame_%04d.webp \
  -map "[mc]" -fps_mode passthrough -c:v libwebp -quality 80 frames-mobile/frame_%04d.webp
```

`-fps_mode passthrough` חובה. בלעדיו ffmpeg משכפל פריימים בחיבורים והגלילה נתקעת בכל מעבר.

| 0 – 0.05 | בטן המטוס, הרמפה פתוחה | שלושים אלף רגל מעל המתחרים. |
| 0.08 – 0.172 | נפילה חופשית מעל העננים | חנויות דרופשיפינג · דרופ מדויק · מהספק ישר ללקוח. בלי מחסן ובלי מלאי. |
| 0.222 – 0.315 | מסוקים מעל העיר | ELYOTAM, וחמשת השירותים מתחת |
| 0.375 – 0.465 | טנק ברחוב, חיילים מאחוריו | אתרי תדמית · פורצים קדימה · אתר שמציב את העסק בחזית. |
| 0.505 – 0.59 | החדר והכוונת של הצלף | דפי נחיתה · בול פגיעה · דף אחד, מטרה אחת: |
| 0.597 – 0.642 | דרך הכוונת לפיצוץ, ואבק | "לקוח" לבד, גדול, ננעל במרכז הפיצוץ |
| 0.648 – 0.74 | חוליה לאורך קיר, רחפנים מעל | אוטומציות AI · חוליה שלא ישנה · סוכני AI שמטפלים בכל פנייה, מסביב לשעון. |
| 0.815 – 0.905 | משגר רקטות יורה, מטוסים מעל | פיתוח אפליקציות · עליונות אווירית · כשהאפליקציה שלך באוויר, למתחרים אין שמיים. |

לפני שמזיזים תזמון, פותחים את `frames/frame_XXXX.webp` (אינדקס = progress כפול 1099,
ועוד 1) ומוודאים שהסצנה מתאימה.

## קופי

שפה מבצעית (שעת אפס, קו אספקה, המטרה ננעלה, אישור לשיגור, פקודת מבצע, לפתיחת קשר). כל כותרת
מצביעה על מה שבפריים ואומרת במדויק מה השירות עושה. השירותים, בשמות שלהם בדיוק: אתר תדמית,
דפי נחיתה, פיתוח אפליקציות, אוטומציות AI, חנויות E-commerce ו-Dropshipping.
שמות לטיניים בתוך משפט עברי (`App Store`, `Google Play`) עטופים ב-`<bdi>`, אחרת סדר המילים
והנקודה מתהפכים.

## סימן החיסול על הפיצוץ

כרטיס דפי הנחיתה נגמר ב"דף אחד, מטרה אחת:", והמילה "לקוח" מופיעה לבד ב-`#zone-target`, במרכז
המסך, בדיוק כשהמטען מתפוצץ. `targetLockTween()` ב-`main.js` מריץ את הרצף על ה-timeline של הגלילה
לפי `TARGET = { in: 0.597, out: 0.632 }`:

1. כוונת צלף (SVG: עיגול, טבעת מקווקוות שמסתובבת, קווי כוונת) נכנסת מסתובבת מרחוק ונועלת על המילה.
2. **פגיעה** ב-`in + 0.01`, על שיא הפיצוץ: ה-X של סימן הפגיעה מכה, הבזק כתום, והכוונת והסימן רועדים.
3. חותמת "המטרה הושגה" נוחתת מתחת למילה, מוטה.

גלילה אחורה מריצה את הכל הפוך. הזרועות של ה-X בנויות כ-`<i>` שמחזיק את הזווית ו-`<b>` שמונפש,
כדי שה-tween לא ידרוס את הסיבוב. בכוונה החותמת היא "המטרה הושגה" ולא "חוסל", כי "לקוח חוסל" נקרא לא נכון.

## העיצוב מתחת לסרט

`field.css` נטען אחרי `styles.css` ודורס רק את מה שמתחת ל-hero, ואת שורת הסיום שמעבירה אליו.
רקעים בגווני זית, כיתוב בצבע חול, וכתום אחד (`--signal`) לכל מה שמבקש פעולה. מפת קווי גובה עדינה
ברקע, תגיות סקשן כחותמת, כותרות ב-Karantina, כרטיסים עם פינות כוונת, וכפתורים עם פינות חתוכות.

## החמ״ל: דף הקשר

`contact.html` מקושר מהכפתור "לתיאום תדריך", מ"קשר לחמ״ל" בסיום ומהפוטר. הטופס:

- **מייל:** `contact.js` שולח ל-`https://formsubmit.co/ajax/elyotam.finance@gmail.com`.
  **בפעם הראשונה** FormSubmit שולח מייל אימות לתיבה הזו, ושום פנייה לא נמסרת עד שלוחצים על
  הקישור שבו. אחרי האימות FormSubmit נותן כתובת מוסווית; כדאי להחליף אותה ב-`ENDPOINT` כדי שהמייל
  לא יופיע בקוד של הדף.
- **וואטסאפ:** "שליחה בוואטסאפ" פותח את 052-2057074 עם כל הפרטים כבר כתובים בהודעה.
- חובה: שם, טלפון, מייל, בחירה של לפחות תחום אחד, ותדריך. רק שם העסק לא חובה. אותה בדיקה רצה גם
  לפני שליחה בוואטסאפ. שדה נסתר (`_honey`) עוצר בוטים. אם השליחה למייל נכשלת, מוצגת הפניה לוואטסאפ.

## עברית / אנגלית

ה-HTML נשאר בעברית. `i18n.js` רץ בסוף ה-`<body>`, לפני `main.js`, ובאנגלית מחליף את התוכן של כל
אלמנט ברשימה שלו (סלקטור ← HTML), מחליף מאפיינים (placeholder, aria-label, meta) והופך את הדף ל-LTR.
הוא רץ לפני שה-hero מפצל אותיות ומילים, ולכן כל האנימציות עובדות על הטקסט באנגלית.

- **הבחירה:** קודם `?lang=en` / `?lang=he` בכתובת, אחר כך הבחירה האחרונה ששמורה ב-localStorage, ואחרת עברית.
  לחיצה על המתג שומרת את הבחירה וטוענת את הדף מחדש.
- **מניעת הבהוב:** סקריפט קטן ב-`<head>` מסמן `i18n-pending` כשהשפה אנגלית, והגוף מוסתר עד שהתרגום הוחל.
- **מחרוזות בתוך סקריפטים:** `window.t(key, hebrew)`. תוויות הפס הצדדי ב-`main.js`, והודעות הטופס,
  הודעת הוואטסאפ ונושא המייל ב-`contact.js`.
- **הוספת טקסט חדש לאתר:** מוסיפים שורה ל-`INDEX.text` או `CONTACT.text` ב-`i18n.js`, אחרת הוא יישאר בעברית גם במצב אנגלית.
- **אורכים:** באנגלית כותרות הסרט קטנות יותר, וה-lead והשורות בסיום קטנים יותר בטלפון, כדי שכל
  `.reveal-line` יישאר בשורה אחת. נבדק ב-320 עד 1600.

## מה עוד צריך לפני שעולים לאוויר

- **הסטטיסטיקות** הן עובדות שנובעות מההצעה עצמה (24/7, 5 כוחות, איש קשר אחד). אם יש מספרים
  אמיתיים, כמו כמות פרויקטים שעלו, אפשר להחליף.
- **אימות FormSubmit.** לשלוח פנייה אחת מהאתר ולאשר את המייל שמגיע, אחרת פניות לא יגיעו.
- **פרטים בתוך הסרט.** בסצנת הצלף תלויים בדים ירוקים-לבנים שנראים כמו דגלים, ועל דלת
  משאית המשגר יש כוכב לבן. כדאי להחליט אם זה בסדר לאתר עסקי, או לייצר את שני הקטעים מחדש.
